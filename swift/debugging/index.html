Debugging

Find and fix bugs faster with LLDB, breakpoints, sanitizers, structured logging and a repeatable method for diagnosing production issues.

Beginner → Advanced 12 articles
#debugging #lldb #xcode

Debugging is a skill with a method: reproduce reliably, inspect the real state instead of guessing, fix the root cause, then prove the fix. This section gives you the tools — LLDB, breakpoints, sanitizers, structured logging — and a workflow for using them.

New to the debugger? Start with Breakpoints and LLDB Commands. If you chase crashes, read Crash Log Interpretation and the sanitizer articles. For production-only issues, OSLog, MetricKit and Common Production Issues are the practical entry points.
