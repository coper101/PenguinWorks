Mid Architecture

Compare MVC and MVVM for a SwiftUI app.

MVC in Apple's tradition puts coordination in the view controller, which tends toward huge controllers and weak testability. MVVM moves presentation state and logic into a view model that exposes observable state; the view binds to it. With @Observable, view models are lightweight and testable without a UI.

MVVM fits SwiftUI naturally because views are declarative. The cost is that view models can grow into god objects if given too many responsibilities; split by feature and keep the domain, persistence and networking behind protocols.

    let (data, _) = try await URLSession.shared.data(from: url)
    return try JSONDecoder().decode(T.self, from: data)
}
