Understand your SwiftUI app before you change it.

ViewGraph is a macOS app that reads a SwiftUI project and draws the view graph: which screens exist, which components they are built from, how they connect, what their previews look like, and what a Git commit actually touches.

It is a comprehension tool that sits beside Xcode and your AI assistant — not a replacement for either. It runs locally on your Mac.

Four questions ViewGraph answers

Each one is a view onto the same analyzed graph.

Screens & navigation

How do I get from this screen to that one?

Screens and their navigation connections are laid out so you can follow the flow instead of guessing from call sites. Sheets, pushes and the app root show up as distinct connections.

Components & reuse

Which screens use this component?

Select a component to highlight every screen that reuses it, and select a screen to see the components that make it up. Reuse that is invisible in source becomes obvious on the canvas.

SwiftUI previews

What does this screen actually render?

ViewGraph discovers the previews you already authored, prepares a host, renders them in the iOS Simulator, and attaches the images to the graph. They are cached per revision.

Commit impact

What did this commit really change?

Compare the graph across two revisions and see which screens, components and files a commit affects before and after, without reading the whole diff.

What it is, and what it is not

ViewGraph is early, and it is deliberately honest about that.

ViewGraph analyzes Swift source statically with swift-syntax. That means it can show structure the compiler understands, but it cannot know everything a running app does. Navigation built from data at runtime, or destinations chosen by a string, may not resolve into a connection. The canvas reports unresolved relationships rather than pretending they are complete.

Previews are rendered through Xcode and the iOS Simulator, so preview workflows need a working Xcode installation. Without it, analysis, the canvas, bookmarks and Git history still work; previews report that the toolchain is unavailable. Some project structures and preview edge cases are unsupported in the current alpha.

The production app has no telemetry and no application-managed networking. Xcode and Swift Package Manager may still download dependencies during preview workflows, and previewed project code can perform its own network requests.
